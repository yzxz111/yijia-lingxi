# 一加灵犀 v0.1.0

版本日期：2026-11-25。[源码仓库](https://github.com/yzxz111/yijia-lingxi) · [版本分发](https://github.com/yzxz111/yijia-lingxi/releases)。

## 本版内容

基于 Electron、React 和 Vite 的 Windows AI 桌面客户端，包含多轮流式对话、6 类场景助手、Markdown 展示、文本附件、本地历史、收藏、搜索、重命名和导出。

通过受限 IPC 连接统一网关，获取授权模型与实时额度，支持 SSE 中文分片解码、请求取消、断流及错误处理。API Key 仅在运行内存中使用。

## 使用方式

- Windows x64：完整解压 `yijia-lingxi-0.1.0-windows-x64.zip`，运行目录中的 `一加灵犀.exe`，无需安装 Node.js。
- 源码：准备 Node.js 22.12+（推荐 24）和 npm，在源码根目录运行 `npm ci`、`npm start`。
- 默认可离线演示。真实聊天需要自行配置兼容网关与有效 API Key。

Windows ZIP 的 SHA-256 见同批次的 `SHA256SUMS.txt`。应用未做 Windows 代码签名。

## 已知限制

真实一加中台与真实云模型仍待联调；演示回复是带明确标记的本地预设。当前没有账号登录、套餐购买、云同步、聊天加密、多模态、RAG 或自主工具执行。

聊天与收藏保存在本机，重要内容请导出；聊天数据不会因为关闭窗口而自动清除。
